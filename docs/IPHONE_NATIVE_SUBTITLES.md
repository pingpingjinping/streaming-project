# 아이폰 기본 전체화면 자막

외부 iframe 영상은 부모 사이트의 HTML/ASS 자막 레이어를 아이폰 기본 영상 전체화면으로 가져갈 수 없습니다. 이 선택 기능은 사이트가 **현재 선택한 자막**을 WebVTT로 전달하고, Safari userscript가 실제 영상에 한국어 `<track>`을 붙입니다. 기존 DB·매칭·자막 파일 및 웹 전체화면 동작은 유지합니다.

## 설치 및 사용

1. 이 변경을 머지하고 Pi의 `streaming-project`를 pull·빌드·재시작합니다.
2. Safari의 기존 userscript 관리 앱에서 [스크립트](https://yjhmoon.iptime.org/userscripts/walnutpi-native-subtitles.user.js)를 설치·활성화합니다. 설치 파일은 `public/userscripts/walnutpi-native-subtitles.user.js`입니다.
3. Safari 확장 프로그램 실행 권한에 **네 사이트와 현재 외부 영상 iframe 도메인**을 모두 허용합니다. iframe 안에서 실행되어야 하므로 네 사이트만 허용하면 영상에 접근할 수 없습니다. `@noframes`는 추가하지 않습니다.
4. 재생 페이지를 새로 열고 자막을 선택합니다. 하단의 **영상 자막 연결됨** 표시를 확인합니다.
5. 전체화면 버튼을 누릅니다. 사이트 버튼에서 Safari가 터치 권한을 전달하지 않으면 웹 전체화면을 사용합니다. 주소창 없는 기본 영상 전체화면을 확인하려면 **영상 안의 전체화면 버튼**을 누릅니다. 접근 가능한 기존 버튼은 userscript가 연결하며, 해당 버튼을 찾지 못하면 영상 안에 작은 확대 아이콘을 표시합니다. 이 보조 아이콘은 영상 터치 후 3.5초 동안 표시됩니다.

안드로이드와 PC에는 이 userscript 기능을 적용하지 않습니다. userscript 미설치·미연결·자막 로딩 실패 시 기존 웹 전체화면을 계속 사용할 수 있습니다.

## 동작 범위

- 설치 메타데이터는 외부 iframe의 변경되는 도메인도 포함하려고 HTTP/HTTPS에 매칭합니다. 그러나 **부모 창의 실제 origin이 `yjhmoon.iptime.org`인 iframe에서, 사이트 연결 요청을 받은 경우에만** 영상·자막·버튼을 변경합니다. 다른 사이트와 최상위 페이지에서는 영상을 변경하지 않습니다. 도메인 권한을 더 좁히려면 사이트 + 실제 iframe 도메인으로 제한할 수 있습니다.
- 자막 검색·다운로드·계정 인증은 사이트에서 수행합니다. userscript는 별도로 원본 자막 서버나 DB를 조회하지 않고, 선택한 대사와 싱크만 전달받습니다. 사이트는 현재 iframe 창·origin·세션 및 자막 revision이 맞는 응답만 처리합니다.
- 선택 자막·싱크 변경, 자막 OFF, 영상 교체, iframe 새로고침에 따라 트랙을 교체/제거합니다. 이전 자막의 늦은 로딩 응답은 무시합니다. 생성한 Blob URL은 교체·종료 시 해제합니다.
- 인라인 재생에서는 새 트랙을 숨겨 기존 ASS/HUD와 겹치지 않게 하고, 실제 영상 전체화면에서만 표시합니다. 외부 영상의 다른 자막 트랙은 그동안 숨겼다가 종료 시 기존 상태로 복원합니다.
- ASS 효과·폰트는 그대로 옮겨지지 않습니다. 기본 전체화면에서는 WebVTT 대사와 브라우저의 자막 표시를 사용합니다. 기존 자막 글씨체 userscript와 함께 사용할 수 있지만 구체적인 스타일은 Safari 버전에 따라 달라질 수 있습니다.
- 여러 영상이 동시에 재생되거나 영상이 추가 중첩 iframe/닫힌 shadow DOM 안에 있으면 현재 버전은 임의로 영상을 선택하지 않습니다. 연결되지 않으면 기존 웹 전체화면을 사용합니다.

## 검증 및 실기기 확인

메시지 범위 제한·선택 자막 전달·싱크 방향·이전 ACK 차단·iframe 재로딩·영상 교체·자막 OFF·전체화면 거부·트랙 실패·중복 표시 방지·종료 복원·터치 버튼 표시를 자동 테스트합니다. Safari 실기기의 Blob WebVTT 로딩과 시스템 전체화면 렌더링은 자동 테스트로 보장하지 않습니다.

아이폰에서는 `영상 자막 연결됨` → 영상 안 전체화면 → 대사 표시 → 종료 → 자막 변경 및 싱크 변경 → 다시 전체화면 순서로 확인합니다. 정상 연결 표시가 있어도 실제 전체화면에서 자막이 빠지면 Safari 버전과 이 단계를 기록해 WebVTT 로딩/시스템 렌더링 경로를 추가 확인합니다.
