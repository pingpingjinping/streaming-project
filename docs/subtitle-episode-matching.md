# 자막 회차 추출 규칙과 회귀 검증

## 회차의 두 번호

- `episode`: 작품 페이지의 회차. 2기 1화라면 1.
- `sourceEpisode`: 제작자 파일 번호. 시작 회차가 13이면 `13 + episode - 1`.
- 글·첨부 라벨·다운로드 응답 파일명·ZIP 경로의 정보를 함께 검사한다.
- `S02E01`은 명시적인 시즌 내 번호다. 시즌 폴더와 bare 파일 번호는 시작 회차와 함께 확인한다.
- 시즌 폴더 안에 `01`과 `13`이 모두 있어 두 번호 체계가 경쟁하면 자동 선택하지 않는다.

## 자동 선택 조건

1. 명시된 시즌 또는 회차가 요청과 충돌하면 해당 후보를 제외한다.
2. ZIP 안의 시즌 폴더도 확인한다. `Season 1/01.srt`와 `Season 2/01.srt`를 구분한다.
3. ZIP 파일 개수를 시즌 수로 나누거나, 이름순으로 회차를 배정하지 않는다.
4. `1-12`는 범위 정보다. 단일 `1-12.srt`를 열두 회차로 취급하지 않는다.
5. 파일에 회차가 없으면 정확한 단일 회차를 가리키는 상위 근거가 필요하다. 범위만으로는 부족하다.
6. 충돌로 제외된 링크를 원시 HTML 재검색으로 다시 가져오지 않는다. 같은 Drive ID의 라벨이 상충해도 제외한다.
7. 다운로드 링크는 본문을 우선 사용하며 사이드바·관련 글·스크립트는 제외한다. 이미지의 alt/title도 첨부 라벨로 확인한다.
8. 수동 ZIP 자동 배치에도 같은 규칙과 작품별 시작 회차를 적용한다. 모호하면 오류 안내 후 개별 파일 직접 선택을 사용한다.
9. 사용자가 개별 파일이나 명시적 회차 배치를 직접 선택한 경우에는 그 수동 지정을 따른다.

## 재현 사례

테스트는 실제 신고 사례의 최소 조건을 HTML/ZIP fixture로 재구성한다. 실제 자막 대사는 저장하지 않으며 외부 HTTP를 전부 대체하므로 원문 수정이나 사이트 장애와 무관하게 재현된다.

| 사례 | 재현 조건 | 기대 결과 |
| --- | --- | --- |
| 스모모 최신 글에서 이전 화 선택 | `/370`, 글 12화, ZIP 내부 01 | 해당 글에서 1화 자동 선택 금지; 별도 1화 글을 탐색 |
| 스모모 2기 누적 번호 | `/376`, 글 13화, `Seihantai - 13.zip 0.01MB`, 내부 13 | 시작 회차 13일 때 작품 1화로 선택 |
| 카이란 월별 글 | `/2026/09/1.html`, 실제 제목 23화 | URL 숫자 1을 근거로 선택하지 않음 |
| 드라이브 HTML fallback | 글 1화, 첨부 라벨 12화, raw HTML에 같은 URL | 제외 유지 |
| 다운로드 응답의 실제 이름 | 글·링크 1화, Content-Disposition 파일명 12 | 제외 |
| 여러 시즌 ZIP | 1~24 파일, 요청 2기 1화, 경계 설정 없음 | 파일 개수로 13화 추정 금지 |
| 시즌별 하위 폴더 | Season 1/01, Season 2/01 | 요청 시즌의 파일 선택 |
| 작품별 시작 회차 | 설정 13, 페이지 1·3·12화 | 원본 13·15·24 선택 |
| 원본 번호가 없는 경우 | 설정 13, ZIP에 bare 01만 존재 | 01로 재시도하지 않음 |
| 수동 ZIP 업로드 | 13~24, 설정 13 | 작품 1~12에 저장 |
| 이름순 배치 금지 | ZIP 이름 1~2, 내부 a.srt와 b.srt | 자동 배치 중단 |
| 포맷 회귀 | UTF-16 SAMI, HEAD/STYLE 포함 | 정상 디코딩 |

`/376`의 글 제목과 첨부 라벨은 2026-09-29 조회로 확인했다. `/370`과 카이란 사례는 사용자 신고 및 기존 코드 경로에 근거한 재구성이다. 테스트 통과는 실제 영상과 자막의 대사·싱크 일치까지 보장하지 않는다.

## 실행

```sh
npm ci
npm run test:subtitles
npm run build
```

PR #48 최초 버전에서 첫 6개 회귀 테스트가 실패하는 것을 확인한 뒤 수정했다. CI에서도 같은 테스트와 Next.js 프로덕션 빌드를 실행한다. Pi의 운영 파일·DB를 변경하지 않고 임시 폴더만 사용한다.

## 운영 확인

머지·Pi 배포 후 스모모 1화/12화, 시작 회차 13인 작품의 1화/3화/12화, 카이란 이미지 링크를 확인한다. 자동 선택이 중단되면 시작 회차를 확인하거나 개별 자막을 직접 선택한다. 기존에 저장된 업로드·캐시의 과거 오매칭은 이번 추출 규칙 적용과 별개이므로 잘못 저장된 항목은 직접 교체해야 한다.
